## DevOps Definition

DevOps is a cultural and technical movement that unifies **software development (Dev)** and **IT operations (Ops)** to shorten the systems development lifecycle while delivering features, fixes, and updates frequently and reliably. It breaks down silos between teams by fostering collaboration, shared responsibility, and continuous feedback.

### Core Principles

- **Collaboration** – Dev and Ops teams work as one unit
- **Automation** – Repetitive tasks are automated to reduce human error
- **Continuous Improvement** – Processes are constantly measured and refined
- **Customer-Centric Action** – Every decision is driven by end-user value

---

## DevOps Lifecycle Stages

| Stage           | Description                                                                                                                                  |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| **Planning**    | Teams define goals, requirements, and roadmaps using tools like Jira or Trello to align development with business objectives.                |
| **Development** | Developers write and version-control code collaboratively, typically using Git with branching strategies like GitFlow.                       |
| **Building**    | Source code is compiled and packaged into deployable artifacts using CI tools such as Jenkins, GitHub Actions, or GitLab CI.                 |
| **Testing**     | Automated tests (unit, integration, performance) validate code quality and catch bugs before they reach production.                          |
| **Release**     | Validated builds are versioned and prepared for deployment, often involving change management and release approvals.                         |
| **Deployment**  | The application is rolled out to production environments using strategies like blue-green or canary deployments for zero downtime.           |
| **Operations**  | The live system is managed and maintained, ensuring infrastructure stability, scalability, and reliability.                                  |
| **Monitoring**  | Logs, metrics, and alerts are continuously tracked (e.g., with Prometheus or Datadog) to detect issues and feed insights back into planning. |
